# Brown Floor Tiles

These 4K maps are from [Poly Haven's Brown Floor Tiles asset](https://polyhaven.com/a/brown_floor_tiles).

- Author: Rob Tuytel
- License: CC0
- Source resolution: 4096 × 4096
- Maps used by Forge3D: diffuse/albedo, OpenGL tangent-space normal, roughness, and ambient occlusion
- Physical material width: 1.7 m

The source maps remain in JPEG form on disk. Forge3D decodes them once when the showcase material is first rendered, creates mip levels, stores albedo in sRGB, and stores the normal, roughness, and AO maps in linear formats.
